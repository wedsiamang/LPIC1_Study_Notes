## まとめノート

### /proc と /sys

```bash
# 接続されているUSBデバイス一覧
lsusb

# PCIデバイス一覧
lspci

# ロード済みカーネルモジュール一覧
lsmod

# モジュール情報を表示
modinfo <モジュール名>
```

| ディレクトリ | 役割 |
|------------|------|
| `/proc` | カーネルとプロセスの情報（仮想FS） |
| `/sys` | デバイスとカーネルの設定（仮想FS） |
| `/dev` | デバイスファイル |

### モジュール操作

```bash
# モジュールをロード（依存関係も自動解決）
modprobe <モジュール名>

# モジュールをアンロード
modprobe -r <モジュール名>
# または
rmmod <モジュール名>

# 設定ファイル
/etc/modprobe.d/
```
