# ⚡ つまづきメモ集

理解に詰まった箇所・AIで腑に落とした記録をここに集約します。

> **書き方のルール**  
> - 「どこで詰まったか」を正直に書く  
> - AIに聞いた質問と、それで腑に落ちた説明を記録する  
> - 後から検索しやすいようにコマンドはコードブロックで書く

---

## テンプレート

```markdown
### [日付] タイトル（どこで詰まったか）

**詰まった状況**  
〇〇をやろうとしたら、〇〇というエラーが出た / 〇〇の意味がわからなかった

**試したこと**  
〇〇を試したが、△△だった

**解決・理解できたこと**  
AIに「〇〇」と聞いたら、こう説明してもらった → 腑に落ちた

**コマンド例**
```bash
# 解決に使ったコマンドや確認方法
```

**ポイント（一言まとめ）**  
〇〇は〇〇のことだった
```
