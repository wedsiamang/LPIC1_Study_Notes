## まとめノート

### ランレベルと systemd ターゲットの対応

| ランレベル | systemd ターゲット | 意味 |
|-----------|------------------|------|
| 0 | poweroff.target | シャットダウン |
| 1 | rescue.target | シングルユーザモード |
| 2,3,4 | multi-user.target | マルチユーザ（CLI） |
| 5 | graphical.target | グラフィカルログイン |
| 6 | reboot.target | 再起動 |

```bash
# 現在のターゲット確認
systemctl get-default

# ターゲット変更（次回起動から）
systemctl set-default multi-user.target

# 今すぐ変更
systemctl isolate multi-user.target

# シャットダウン・再起動
shutdown -h now
shutdown -r now
reboot
halt
poweroff
```
