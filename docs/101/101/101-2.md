## まとめノート

### 起動シーケンス

```
BIOS/UEFI → ブートローダー(GRUB2) → カーネル → initramfs → init(systemd)
```

```bash
# カーネル起動メッセージを確認
dmesg
dmesg | less

# 起動時のカーネルパラメータ確認
cat /proc/cmdline
```
